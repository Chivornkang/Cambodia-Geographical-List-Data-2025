# Cambodia Geographical List 2025

A standardized dataset of Cambodia's official administrative divisions, from provinces and capital to districts, communes, and villages.

Includes:
- Official administrative codes.
- Khmer and English location names.
- Hierarchical administrative structure.
- Data organized in the `src/` folder.

## Data Source

Cambodia Ministry of Economy and Finance (MEF) – Open Data Portal.

[Official Dataset – Cambodia Geographical List 2025](https://data.mef.gov.kh/datasets/pd_68e370856a965e00074a5e7b)
